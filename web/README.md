# web — фронтенды cue-vision

npm workspaces. Сейчас здесь одно приложение — тренировки; табло и панель маркера
появятся рядом в `apps/`, общий код — в `packages/`.

| Каталог | Что это |
|---|---|
| `apps/training` | тренировки игрока: список, статистика, удары (Vue 3 + TypeScript + Vite) |
| `packages/` | общий код фронтов (пока пусто: API-клиент и компоненты стола переедут сюда со вторым приложением) |

## Запуск

Нужен Node 22+ и запущенный cue-vision (по умолчанию `http://localhost:8080`).

```
npm install
npm run dev          # http://localhost:5173
```

Dev-сервер проксирует `/api` в cue-vision: у сервера нет CORS. Адрес и токен — в
`apps/training/.env.local` (образец — `.env.example`); токен подставляет прокси, в
браузер и в сборку он не попадает.

## Проверки

```
npm run lint         # oxlint, конфиг — .oxlintrc.json (общий для всех приложений)
npm run typecheck    # vue-tsc
npm run build
```

## Устройство приложения

```
src/
  api/          клиент /api/v1 и типы ответов (зеркало структур internal/store)
  composables/  useAsync — загрузка с отменой при смене параметров
  components/   переиспользуемые куски интерфейса
  lib/          форматирование чисел, дат, подписи луз и исходов
  router/       маршруты; страницы грузятся лениво
  views/        страницы
```

Типы в `src/api/types.ts` написаны руками по `internal/store/*.go`. Меняя JSON в
сервере, правьте их в том же коммите; позже их заменит генерация из OpenAPI.
